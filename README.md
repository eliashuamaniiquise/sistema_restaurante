# Sistema DR — Restaurante Don Dunay

Sistema Web de Gestión de Pedidos, Mesas, Productos, Inventario y Pagos (POS) desarrollado en **HTML5, CSS3, JavaScript, PHP 8+ y MySQL**.

## Instalación rápida en XAMPP
1. Copiar la carpeta `sistemdr-don-dunay` dentro de `C:\xampp\htdocs\`.
2. Iniciar **Apache** y **MySQL** en el Panel de Control de XAMPP.
3. Abrir `http://localhost/phpmyadmin`, ir a la pestaña **Importar** y ejecutar el archivo `database.sql`.
4. Abrir en el navegador: `http://localhost/sistemdr-don-dunay/`.
